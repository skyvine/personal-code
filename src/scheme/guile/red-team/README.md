# Red Team Scripts

This directory contains scripts that are useful for red-teaming. These are personal
scripts that suit my tastes, and I find them useful, but they are not industrial grade.

Red teaming is an activity where authorized people attempt to attack a network in order to
help the administrators understand how to better secure it. Red teaming against people
without their consent is not OK and you are responsible for any damage you cause.

## On Publishing Exploits

This repository will contain some "exploits" that are useful as examples to understand how
the scripts are meant to be used and to try them out in test environments. However, it
will not contain creative exploits that are useful in the wild.

It is good for repositories like nmap scripts to exist for the purpose of testing for the
existence of vulnerabilities on live systems. These repositories are managed in
responsible ways and do not 0-day people; scripts are added to them after the CVE is
published and fixes or mitigations have propagated. These are valuable as a communal
effort to ensure equal access to security knowledge. That is not the purpose of this
repository.
